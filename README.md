# Today Is Menu

A simple web app that answers the daily question: "What should I eat today?"

## Live Website
[Today Is Menu](https://wasineesaa.github.io/today-is-menu/)

## Features

- Random food menu generator
- Filter by food category
- Menu recommendations for users
- Works directly in the browser, no installation needed

## Technologies

- HTML
- CSS
- JavaScript
- GitHub Pages
